QUAN LY QUAN AN - HTML/CSS/JS ENHANCED

Mo index.html bang Chrome/Edge.
Khong can Node.js.

JavaScript da duoc nang cap:
- Du lieu luu vao LocalStorage, refresh trang khong mat du lieu.
- Dashboard tu tinh doanh thu, chi tieu, loi nhuan, so don.
- Tao don hang va tu dong tinh tien.
- So luong ban cua mon tu dong tang khi tao don.
- Tim kiem + loc don hang.
- Bam vao trang thai de chuyen: Cho xu ly -> Dang lam -> Hoan thanh.
- Xoa don hang.
- Them / sua / xoa mon an.
- Them / xoa khoan chi.
- Danh sach khach hang tu dong tong hop tu don hang.
- Thong bao toast.
- Nut thong bao hien so don dang cho.
- Khoi phuc du lieu demo.
- Responsive.

Luu y: day van la frontend demo. De thanh phan mem that, buoc tiep theo noi JavaScript voi Java Spring Boot + MySQL.


BẢN CẬP NHẬT BÀN ĂN:
- Quán có cố định 7 bàn (Bàn 1 đến Bàn 7).
- Dashboard hiển thị tình trạng 7 bàn.
- Có trang Bàn ăn để xem bàn trống/có khách.
- Khi tạo đơn có chọn Bàn số.
- Có thể bấm vào bàn để gọi món.
- Có thể thanh toán/dọn bàn; các đơn đang mở của bàn chuyển sang Hoàn thành.
- Trạng thái bàn lưu theo dữ liệu đơn hàng trong LocalStorage.
